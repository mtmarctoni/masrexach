## GitHub social preview

In the repository’s **Settings → General → Social preview**, upload `social-preview.jpg`. Adding the image to Git does not activate it as GitHub’s repository preview. Keep repository visibility unchanged.

## Font notices

The bundled Fraunces and Instrument Sans fonts use the SIL Open Font License 1.1. Their copyright notices and license are included beside the fonts in [`src/assets/fonts/OFL.txt`](../../src/assets/fonts/OFL.txt).

The notices preserve both the Fraunces upstream license’s 2018 copyright and the bundled font’s embedded 2020 copyright. Instrument Sans’s embedded 2022 copyright matches its upstream license.

Upstream license references:

- [Fraunces](https://github.com/google/fonts/blob/main/ofl/fraunces/OFL.txt)
- [Instrument Sans](https://github.com/google/fonts/blob/main/ofl/instrumentsans/OFL.txt)
